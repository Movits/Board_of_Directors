# Sobre esta pasta
Aqui vivem as **atas das reuniões** do conselho.

No app, toda reunião concluída tem o botão **🧠 Exportar ata (Obsidian)** — no
painel do veredito e em cada item do Histórico. Ele baixa um arquivo
`AAAA-MM-DD - <ideia>.md` com:

- frontmatter YAML (data, placar, situação do [[Consenso Pleno]], modelo…),
  pronto para consultas do Obsidian (Dataview etc.);
- *wikilinks* para as notas dos conselheiros — a ata se conecta sozinha ao
  grafo;
- análises, [[Debate|debates]] com ressalvas pendentes por rodada, veredito
  íntegro e o prompt de execução.

**Solte o arquivo baixado nesta pasta** e pronto. O export é de mão única: o
app não lê o vault — a memória viva do app fica no
[[Armazenamento Local|localStorage]], e este vault é o arquivo permanente.
